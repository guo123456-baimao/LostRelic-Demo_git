## 1. 文档目的与使用约定

本文档定义 Demo 的技术栈、玩法、系统架构、数据结构、场景流程与素材路径。Codex 实现时必须遵守；素材引用一律使用本工程内真实存在的路径（已核对）。仍可选的素材（终局特效、语音等）未提供时允许省略或用简单占位，交付时在 README 中列出所有占位与替换点。

## 2. 技术规格（必须遵守）

- Unity 2021.3.45f1 LTS（当前工程版本），不升级主版本
- 渲染管线：URP 12.1.15（已安装 `com.unity.render-pipelines.universal`）；URP Asset 已配置到 Graphics Settings（Assets/Settings 下多档管线资产），默认按 High 档实现；材质统一使用 URP Lit，场景中 Global Volume 已有后处理
- 热更新：**xLua 已安装**（`Assets/Assets/XLua`，原生插件 `Assets/Assets/Plugins/xlua.bundle`）；玩家、交互、背包、任务、对话、敌人遭遇、音频切换等**游戏逻辑全部写在 Lua**，C# 仅做框架与 SDK
- 资源加载：**Addressables 已安装**（`com.unity.addressables` 1.19.19）；Prefab、Sprite、音频、字体、Lua 脚本与 JSON 配置统一通过 Addressables 加载；v1 使用本地组，后续扩展远程组实现资源热更
- UI：uGUI（工程已内置 com.unity.ugui）；所有文本（HUD/背包/对话框/提示）使用 `Assets/Assets/Text.ttf`（导入后生成 TMP Font Asset 或直接用于 uGUI Text，确保中文正常显示）
- 场景：**复用 `Assets/Scenes/SampleScene.unity`**（已含遗迹环境：LevelTest/Walls/Pillars/Props/Decors/Lighting/Platform/Directional Light/Main Camera/Global Volume），不重建环境，仅在该场景内添加玩家、NPC、猫头鹰、敌人、UI 与逻辑
- 输入：旧 Input Manager，键鼠操作（WASD + 鼠标 + E 交互 + Tab 背包）
- 数据：物品/任务/对话/音频使用 JSON（Assets/_Project/Data 下），由 Lua 读取
- 目标：Editor 内可运行，Windows Standalone 可构建

## 3. 游戏概述

- 类型：第三人称 3D 探险 Demo（v1 无战斗）
- 剧情（默认）：考古学家进入失落古文明遗迹，找回 4 只猫头鹰雕像并交给老向导/祭坛
- 视角：第三人称跟随相机（默认，可后续改第一人称）
- 时长：3~5 分钟
- 敌人：遗迹守卫（史莱姆，v1 为氛围遭遇——敌人进入警戒即切换 BGM，无战斗）
- 对话：纯文本对话框（无立绘/头像），逐字显示推进剧情
- 核心循环：探索遗迹 → 发现猫头鹰雕像 → 拾取入背包 → 途中遭遇守卫（BGM 切换）→ 集齐 4 只 → 对话推进剧情 → Demo 完成

## 4. Demo 流程（单场景线性流程）

1. 开场：出生点位于 SampleScene 入口，NPC「老向导」触发开场对话，发布主线任务「找回 4 只猫头鹰雕像」
2. 探索：4 只猫头鹰雕像分布在遗迹中，按路线建议放置：入口附近 1 只（教学）、主殿 1 只、侧室/地下 1 只、祭坛/尽头 1 只；具体坐标由 Codex 在场景内实测摆放，确保地面可达
3. 敌人遭遇：遗迹守卫（史莱姆）在若干警戒区巡逻；玩家进入警戒范围 → BGM 切换为 Enemy Spawned.wav，离开警戒范围 → 恢复 Background Music.wav
4. 拾取：按 E 拾取猫头鹰 → 播放拾取音效 → 道具从场景消失 → 背包增加对应道具
5. 集齐 4 只后与老向导（或祭坛）交互 → 终局对话 → 任务完成界面 → 可重新开始

## 5. 系统设计

### 5.1 玩家控制（Lua 实现）

- WASD 移动、鼠标控制相机、Shift 疾跑（可选）、Space 跳跃（可选）
- 使用 CharacterController 做移动与碰撞；玩家 Prefab 为 `Assets/Assets/Player/Prefab/Palyer_prefab.prefab`，Animator 使用 `DogControl.controller`，动画使用 Idle_Battle / WalkForwardBattle / RunForwardBattle（v1 不使用攻击/受击动画）
- 相机：简单第三人称跟随（自写），不依赖 Cinemachine

### 5.2 交互与拾取

- 可交互物统一挂 `Interactable` 组件（C# 只暴露 id、类型、名称、提示文本，不写逻辑）
- 准星/屏幕中心出现交互提示：「E 拾取」「E 对话」
- 拾取流程：玩家按 E → Lua 交互控制器判断物品类型 → 调用背包 Controller 入库 → 场景道具消失 → 播放拾取音效 → 广播事件

### 5.3 背包系统（MVC + 观察者）

- Model：`InventoryModel` 持有槽位列表（id、count、物品配置引用），提供增删改查与容量控制
- View：`InventoryView` 为 uGUI 背包面板（网格格子、图标、数量、名称、描述、关闭按钮），只负责渲染
- Controller：`InventoryController`（Lua）处理打开/关闭/选中/使用，调用 Model，并通过事件通知 View 刷新
- 容量：默认 20 格；猫头鹰雕像为任务道具，不可堆叠，每件占 1 格
- 解耦：所有模块通信只走事件中心，禁止模块间直接引用
- 文本渲染：背包内名称/描述等全部使用 Text.ttf
- 资源引用：面板、图标、字体均通过 Addressables 加载（ResService）

### 5.4 任务系统

- 任务数据：id、名称、描述、目标列表（itemId + count）、完成后动作（触发终局对话）
- v1 主线任务「找回猫头鹰雕像」：收集 `item_owl_1` ~ `item_owl_4` 各 1 只
- 流程：对话发任务 → 拾取时任务追踪器检查 → 进度 UI 更新 → 集齐后广播任务完成

### 5.5 对话系统（纯文本对话框）

- NPC「老向导」默认使用 `Assets/Assets/Old Guide/Old Guide/Characters/fbx/Mage.fbx`（法师形象，符合身份），动画使用 `Rig_Medium_General.fbx` 中的待机/对话动作，贴图 `mage_texture.png`；该包内 Knight/Ranger/Rogue/Barbarian 可作为备选
- **对话框为纯文本**：无立绘、无头像，仅显示说话人名与台词文本；文本使用 Text.ttf
- 数据：对话 id、NPC id、若干句台词（speaker、text）、完成后动作
- 表现：屏幕底部对话框，逐字显示，点击/按键跳过当前句，最后一句结束后执行 onComplete（发任务/完成任务/进入结局）
- 交互：面向 NPC 按 E 开始对话；对话期间锁定玩家移动与交互

### 5.6 事件系统（观察者模式）

- C# 提供 `EventCenter`：Subscribe / Unsubscribe / Publish；Lua 侧封装 `EventBus`，注册的事件必须在系统销毁时反注册，防止泄漏
- 核心事件表：

| 事件 | 载荷 | 触发方 | 主要监听方 |
| --- | --- | --- | --- |
| OnGameStart | — | Bootstrap | 各系统初始化 |
| OnInteract | Interactable | 玩家控制器 | 交互/对话/拾取 |
| OnItemPickup | 物品 id、数量 | 交互控制器 | 背包 Model、任务、UI |
| OnInventoryChanged | 背包快照 | 背包 Model | 背包 View、任务、UI |
| OnInventoryOpened / OnInventoryClosed | — | 背包 Controller | UI、音频（背包点击音） |
| OnQuestStarted / OnQuestProgress / OnQuestCompleted | 任务信息 | 任务系统 | UI、对话、结局 |
| OnDialogStart / OnDialogEnd | 对话数据 | 对话系统 | UI、玩家锁定、任务 |
| OnEnemyAlert / OnEnemyClear | 敌人 id | 敌人警戒区 | 音频系统（BGM 切换） |
| OnGameEnd | 结果 | 任务系统 | Bootstrap、UI |

### 5.7 URP 渲染

- URP 已配置，不再新建管线资产；按 High 档（High_PipelineAsset.asset）运行
- 场景材质统一为 URP Lit；新加入的 Prefab/模型材质如有 Built-in 着色器，需转换为 URP
- Global Volume 已存在于场景，后处理按现配置保留

### 5.8 音频系统（固定配置）

| 用途 | 资源路径 | 播放方式 |
| --- | --- | --- |
| 平时 BGM | `Assets/Assets/Audio/BGM/Background Music.wav` | AudioSource 循环播放 |
| 遇到敌人 BGM | `Assets/Assets/Audio/BGM/Enemy Spawned.wav` | 敌人进入警戒时切换（建议淡入淡出），脱离后恢复 Background Music |
| 拾取道具 | `Assets/Assets/Audio/Sound Effects/sfx_spell 1.mp3` | PlayOneShot |
| 打开背包 | `Assets/Assets/Audio/BGM/Sounds/click-b.ogg` | PlayOneShot |

- 其余 UI 音效可选：`Assets/Assets/Audio/BGM/Sounds/` 下 tap/switch/click 系列；拾取备用 `sfx_item pickup.wav`
- 音频逻辑在 Lua（AudioService 桥接 C# AudioSource），BGM 状态由事件驱动；音频资源经 Addressables 加载

### 5.9 敌人遭遇（v1 氛围版）

- 敌人默认使用史莱姆：`Assets/Assets/Enemies/Prefabs/PBRDefault/SlimePBR.prefab`，Animator 使用 `Assets/Assets/Enemies/Animators/Slime.controller`（Idle/Walk/Run 动画足够本 Demo 使用）；TurtleShell（`TurtleShellPBR.prefab` / `TurtleShell.controller`）可作为备选敌人
- 敌人系统：场景内设置若干「警戒区」（Trigger/Collider + 敌人占位体）；玩家进入警戒区即触发 `OnEnemyAlert`（BGM 切换），离开警戒区触发 `OnEnemyClear`（BGM 恢复）
- v1 敌人不攻击玩家、不可被击杀；巡逻/追逐/战斗行为待后续扩展

### 5.10 xLua 热更新 + Addressables 架构

- C# 框架层（不可热更）：`XLuaManager`（LuaEnv 生命周期、Lua 脚本加载）、`EventCenter`、`UIManager`、`InputService`、`ResService`（基于 Addressables）、`AudioService`、`DataService`、`Interactable` 组件、`GameBootstrap`
- Lua 逻辑层（可热更）：`main.lua`、`player_ctrl.lua`、`camera_ctrl.lua`、`interaction_ctrl.lua`、`inventory_controller.lua`、`quest_ctrl.lua`、`dialog_ctrl.lua`、`enemy_ctrl.lua`、`audio_ctrl.lua`、`event_bus.lua`
- 加载顺序：`main.lua` 启动 → 注册事件 → 初始化各系统
- 资源与脚本加载：Lua 脚本、JSON 配置、Prefab、Sprite、音频、字体均通过 Addressables 加载；建议分组：`ProjectLua`（Assets/_Project/Lua）、`ProjectData`（Assets/_Project/Data）、`UserAssets`（Assets/Assets 下素材）；v1 全部为本地组
- 热更验证方式：修改任一 Lua 脚本后重新进入 Play 即生效（Editor 直读或 Addressables 本地构建均可）；后续扩展为 Addressables 远程组（Lua + 资源一并更新），C# 层无需改动
- 铁律：C# 只提供能力（SDK），所有玩法判断在 Lua

## 9. 验收标准（Codex 完成 Demo 后必须满足）

1. SampleScene 打开可开始，Lua 全部加载成功、无红色报错
2. 玩家使用 Palyer_prefab 移动/相机正常，动画随速度切换
3. 4 只猫头鹰（Quest Item_1~4）均可拾取：拾取后场景中消失，背包出现对应道具，图标统一使用指定 PNG，名称/数量正确
